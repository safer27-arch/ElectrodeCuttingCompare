ElectrodeCuttingCompare v0.7.0 Smart Diagnostic

추가 기능
1. Cutter Profile별 Golden 정상 기준 저장
2. Top3 이상 후보 순간 자동 추출 (A/B 시간 표시)
3. Event 패턴 + Multi-Cycle/Jerk + ROI + Golden 통합 진단
4. px→mm Calibration 저장 (Profile별)
5. Golden 대비 Motion Risk / Nip Offset / Tip Jitter 변화 표시
6. Smart Diagnostic 그래프 터치 전체화면 확대
7. 저장 결과 이미지에 Advanced/Smart Diagnostic 그래프 포함

권장 사용 순서
- Cutter Profile 선택
- A/B 영상 선택
- 자동 보정 및 ROI 설정/분석
- v0.6 고급분석
- 정상 상태가 확인된 영상에서만 Golden 등록
- px→mm가 필요하면 Calibration 설정
- v0.7 통합진단 실행

주의
- Golden은 반드시 정상 상태가 확인된 영상으로 등록하세요.
- 현재 WATCH/이상후보는 예방 품질관리용 후보 판정입니다. 실제 NG 확정 기준은 정상/불량 데이터 검증 후 설정해야 합니다.
- 30fps 영상은 약 33ms보다 짧은 현상을 놓칠 수 있습니다. 빠른 Cutter 이벤트는 120fps 이상 촬영이 가능하면 더 유리합니다.
