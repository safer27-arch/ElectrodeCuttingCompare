v1.9.1 Visual Summary Dashboard · Graph + Table

목표
- 긴 설명을 읽지 않아도 통합검사 결과의 문제 위치를 한눈에 파악
- Cycle뿐 아니라 다른 검사항목도 동일한 그래프/표 방식으로 요약
- 상세 텍스트는 전문가 상세분석 영역에 유지

주요 변경
1) 전체 검사항목 한눈 요약 대시보드 추가
   - A 기준 신뢰도
   - B Cycle 반복성
   - A↔B 평균 궤적
   - 고속 Event
   - Timing/Jerk
   - 공통진동/안정화
   - Smart/Golden
   - ROI Tip/Nip

2) 각 검사항목을 0~100 상대 차이/위험 막대로 표현
   - 낮음 / 중간 / 큼으로 즉시 구분
   - 실행하지 않은 항목은 '미실행'으로 표시

3) 전체 결과에서 위험도가 큰 검사항목 최대 4개를 표로 자동 정렬
   - 검사항목 / 상태 / 핵심 확인 포인트

4) 통합검사 Summary를 3줄 중심으로 축약
   - 검사모드/검사시간
   - 최우선 문제 Cycle + 문제 동작
   - A/B 비교재생 안내

5) 기존 장문 Dashboard 중복 문구는 메인 화면에서 숨김
   - 상세 근거/원본 데이터는 '전문가 상세분석 보기'에서 유지

6) 기존 v1.9 문제 지도, TOP3 표, A/B 즉시 비교재생, Fast Engine, Permanent Signing 유지

주의
- 그래프의 0~100 값은 서로 다른 영상 기반 상대 지표를 보기 쉽게 통일한 표현입니다.
- 검증된 Golden/NG 한계가 확보되기 전까지 품질 불량 확정값이 아니라 비교/추세/확인 우선순위 용도입니다.
