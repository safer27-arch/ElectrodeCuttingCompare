ElectrodeCuttingCompare v1.4.2 Update Test

목적
- 고정 Signing Key 전환 후 기존 앱 위에 APK 업데이트 설치가 되는지 검증합니다.
- 분석 알고리즘은 v1.4.1과 동일하게 유지합니다.

변경사항
- versionCode: 21
- versionName: 1.4.2
- 상단 버전 문구에 UPDATE TEST / Permanent Signing 표시
- GitHub Actions가 Repository Secrets의 전용 고정 키로 release APK를 서명
- signing/, *.jks, *.keystore를 .gitignore로 차단

중요
- 현재 설치된 앱이 이미 같은 고정 키로 설치된 첫 버전이라면 삭제 없이 업데이트되어야 합니다.
- 현재 설치본이 과거 debug 키로 서명된 앱이라면 이번 한 번은 Android 보안상 삭제 후 설치가 필요할 수 있습니다.
- 한 번 고정 키 버전을 설치한 뒤에는 이후 versionCode만 증가시키며 같은 키를 계속 사용합니다.
