# ElectrodeCuttingCompare v1.9.3

## Field Visual Dashboard + Replay Precision
- 현장 가독성 강화: 핵심 글자/수치 확대, 상태 색상 대비 강화
- 검사 결과를 장문 설명보다 그래프/표/상태 배지로 우선 표시
- 전체 검사항목은 `문제 우선도` 기준으로 표시: 높을수록 먼저 확인
- 빠른검사에서 수행하지 않은 항목은 `빠른검사 제외`로 명확히 표시
- 최우선 문제를 대형 카드로 표시: 문제 Cycle / 문제 동작 / 편차
- 문제 Cycle TOP3 버튼을 단순화하여 즉시 A/B 비교재생
- A/B Cycle 비교재생을 TextureView 기반으로 변경하여 SurfaceView 검은 화면/캡처 문제 완화
- 진행률 동기화 기본 ON + 자동 보정으로 같은 0~100% 동작 위치 비교 강화
- 문제 동작구간을 진행바에 형광 표시하고 진입 시 경고 표시
- `문제구간만 반복` 모드 추가
- 기존 Fast Engine, Heatmap, Golden, ROI, Permanent Signing 유지

주의: 영상 기반 상대 진단입니다. 문제 우선도/편차는 검증된 NG 확정값이 아니며 실제 품질 판정 기준은 정상/불량 데이터 검증 후 설정해야 합니다.
