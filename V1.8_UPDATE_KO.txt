ElectrodeCuttingCompare v1.8 Fast Engine

핵심 목표
- 빠른검사 시간을 v1.7.1보다 크게 단축
- 문제 Cycle TOP3 / 문제 동작구간 / A-B Cycle Replay 기능은 그대로 유지

속도 개선
1. Android 9(API 28)+에서는 MediaMetadataRetriever.getFramesAtIndex()를 이용한 Batch Frame Scan을 우선 사용합니다.
   - 여러 프레임을 연속 배치로 읽어 기존의 반복 random seek 횟수를 줄입니다.
2. 빠른검사에서 A/B 영상 Cycle Trace를 2개 Thread로 병렬 추출합니다.
3. 빠른검사에서는 픽셀 Difference Map / 촬영각 정밀 Transform 계산을 생략합니다.
   - Cycle 반복성은 각 영상 내부 좌표를 0~100%로 정규화해 비교합니다.
4. Batch Scan을 사용할 수 없는 기기/코덱은 Scaled Random Scan으로 자동 fallback 합니다.
5. 결과 화면에 실제 사용 Engine, 샘플 수, A/B Trace 추출 시간을 표시합니다.

유지 기능
- A=기준영상(정상 권장), B=비교영상
- Worst Cycle TOP3
- 어느 Cycle의 어떤 동작이 문제인지 표시
- 대기/초기, 전진가속, 커팅/충격, 복귀가속, 안정화 5구간 분석
- Cycle Heatmap
- A 정상 대표 Cycle vs B Worst Cycle 좌우 반복재생
- 불완전 Cycle 자동 제외
- 검사 전체 소요시간 표시
- Permanent Signing (기존 앱 위 업데이트 설치)

주의
- 빠른검사는 Cycle 문제 탐색용입니다. 픽셀 단위 Difference/ROI/Jerk 정밀 원인 확인은 표준/정밀검사를 사용하세요.
- 영상 기반 상대진단이며 실제 NG 한계 또는 mm/속도 실측값은 별도 검증이 필요합니다.
